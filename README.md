# TP CCFL - Prêt de matériel aux associations

Projet d’exploration, d’analyse et de nettoyage des données de prêt de matériel de la CCFL.

Les fichiers sources se trouvent dans `data/`.

## Prérequis

- Python 3.11 ou version plus récente
- pandas

## Installation 

Depuis la racine du projet :

```bash
## sur Windows

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install pandas

## sur macOS

Depuis la racine du projet :

```bash
python3 -m venv .venv
source .venv/bin/activate
python3 -m pip install pandas
